# 📝 Jogo da Forca - Python

Este é um simples jogo da forca desenvolvido em Python, onde o jogador deve adivinhar a palavra sorteada antes de esgotar as tentativas.

## 🚀 Como jogar?

1. Execute o script Python (forca.py).
2. O programa escolherá uma palavra aleatória da lista.
3. Digite uma letra por vez para tentar adivinhar a palavra.
4. Você tem *10 tentativas* para acertar.
5. Se acertar todas as letras antes das tentativas acabarem, você vence!
6. Caso contrário, a palavra correta será revelada ao final.

## 🛠 Tecnologias utilizadas

- Python 3.x
- Biblioteca random (para sorteio das palavras)
